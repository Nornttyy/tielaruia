# 搭一个自己的免费联机服务器 (让联机变稳)

游戏现在联机靠"大家都在蹭"的公共服务器，所以经常连不上。
跟着下面做一次，搭个**只给你自己人用**的免费服务器，联机就稳了。
**全程不用输命令，都是网页上点鼠标。** 大概 10 分钟。

服务器代码我已经写好放在仓库的 `peer-server/` 文件夹里，你只要把它"挂"到 Render 上。

---

## 第一步：注册 Render (免费)

1. 打开 👉 https://render.com
2. 点右上角 **Get Started** / **Sign In**
3. 选 **GitHub** 登录（用你那个有游戏仓库的 GitHub 账号，最省事）
4. 它会问要不要授权访问仓库 → 同意

---

## 第二步：新建一个 Web 服务

1. 登录后，点右上角 **New +** → 选 **Web Service**
2. 找到并选你的游戏仓库 **`tielaruia`** → 点 **Connect**
3. 接下来有个设置表单，按这样填（其他都用默认）：

| 项目 | 填什么 |
|---|---|
| **Name** | `teilaruia-peer`（随便取，但记住它） |
| **Root Directory** | `peer-server` |
| **Build Command** | `npm install` |
| **Start Command** | `npm start` |
| **Instance Type** | 选 **Free**（免费那档） |

4. 拉到最下面点 **Create Web Service**
5. 等它转圈圈部署（1-3 分钟），看到绿色 **Live** 就成了 ✅

---

## 第三步：拿到你的服务器网址

部署好后，页面顶部会显示一个网址，长这样：

```
https://teilaruia-peer.onrender.com
```

**点开这个网址**，如果看到一行字：

```
teilaruia peer server OK ✓
```

就说明你的服务器活了！🎉

---

## 第四步：告诉我网址

把那个网址（比如 `teilaruia-peer.onrender.com`，**不要前面的 https:// 和后面的 /**）发给我。

我会把它填进游戏，推送上线。之后你们联机就走你自己的服务器，稳了。

---

## 几个要知道的小事

- **第一次连会慢几秒**：免费服务器没人用时会"睡觉"，有人连的时候要花 30-60 秒"叫醒"它。叫醒后就正常了。想试可以先点一下上面那个网址把它叫醒。
- **完全免费**：Render 免费档够你俩玩，不会扣钱（它不要你绑卡）。
- **不用维护**：搭一次就行，以后不用管。
