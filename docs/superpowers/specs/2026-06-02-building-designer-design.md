# 建筑设计器 (Building Designer)

日期: 2026-06-02
状态: 实现中

## 目标

让用户 (10 岁) 在浏览器里画建筑，导出一段"设计码"发给 AI，AI 能精确还原看到每一格。
为后续"设计码 → 游戏真建筑 (prefab)"打基础。

## 决策 (已与用户确认)

- **本地双击打开**的单 HTML 文件 (不联网、不依赖服务器、不用装东西)。
- v1 只做"能看到" (画板 + 复制设计码 + 存图片)；"导入游戏当真房子"以后再加。

## 形态

单文件 `building_designer.html` (内联 CSS+JS, 无外部依赖)，放仓库根目录，用户双击打开。

- **网格画板** (`<canvas>`)，默认 24×16 格，每格 ~26px。宽/高可 +/- 调 (调时保留已画内容)。
- **调色板**: 游戏真方块按钮 (色块+中文名)，点选当前方块；含"空(橡皮)"。
- **画法**: 画板上按住拖动画当前方块；右键擦除 (设回空)。
- **按钮**: 清空 / 宽高 +/- / 复制设计码 / 存图片(PNG)。
- 底部只读文本框实时显示设计码 (用户也能直接复制)。

## 方块 ↔ 字符 (跟游戏 village_prefab.char_to_tile 对齐, 便于将来导入)

游戏已有: `P`木板 `L`原木 `W`石头 `D`门 `C`箱子 `B`工作台 `F`熔炉 `T`火把 `_`平台 `.`空。
扩展 (将来在 char_to_tile 补): `g`草 `d`土 `s`沙 `a`砂岩 `v`树叶。

## 设计码格式 (用户粘贴给 AI)

```
=== TEILARUIA 建筑设计码 v1 (24x16) ===
<每行一串字符, . = 空>
图例 P=木板 ... (.=空)
```
自带图例 → AI 一看就懂；尺寸在头里 → 可精确还原。

## 不做 (YAGNI)

- 不联网/不存服务器/不登录。
- v1 不做撤销、图层、复制粘贴框选 (以后按需)。
- v1 不直接生成 .json prefab (等"导入游戏"阶段)。

## 验收

- 双击打开能画、能选方块、能擦、能清空、能改大小。
- 复制设计码 = 可粘贴的字符网格 (尺寸正确、含图例)。
- 存图片 = 能下载 PNG。
- AI 拿到设计码能精确复述每一格。
