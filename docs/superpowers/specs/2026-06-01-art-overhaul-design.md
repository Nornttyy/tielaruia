# 美术大翻新 — 工具 + 方块 (Art Overhaul)

日期: 2026-06-01
状态: 进行中 (分批执行)

## 背景

用户 (10 岁) 要求"优化工具的外形，还有方块"，并补充两点：
- 工具要**更精细**、弯曲的地方**更自然平滑**
- 每个**群系 (biome) 的方块更有特色**

美术全部由 `@tool` 脚本程序绘制 (16×16 ASCII 网格 + 调色板)：
- 工具/物品 → `scripts/art/items_art.gd` (`get_icon(id)`)
- 方块 → `scripts/art/blocks_art.gd` (`get_texture(tile_id)`)

渲染验货工具 (新增)：`scripts/tools/render_art_sheet.gd`
`godot --headless --script res://scripts/tools/render_art_sheet.gd` → `/tmp/art_preview/{tools,blocks}.png`

## 现状诊断 (渲染目视)

工具：
- **镐 ⛏️ (最严重)**：镐头是 3 行高的扁横杠，看着像锤子。8 个等级全这样。
- 剑 🗡️：刀身单薄，缺刀尖收束和血槽。
- 斧 🪓：方块刃，缺弧度。
- 法杖/弓/抓钩：基本 OK。

方块：
- **矿石 💎**：铜/铁/锡/银/煤矿混在土黄色里，矿疙瘩不明显，跟泥土难区分。
- **土/沙 🟫**：像随机噪点，缺结构 (违反"要形状不要散点"规矩)。
- **冰 🧊**：灰扑扑像石头，不像冰。
- 草/石/木/岩浆/地狱石：质量尚可，小修即可。

## 设计方向

### 工具
- **镐头**：中央凸起的"眼"接竖把手，两端走弧线扫下来收成尖；弯角用"小台阶 (stairstep)"过渡显平滑。一套形状模板 + 8 套 tier 配色 (dark/base/hi + 可选 sparkle)。地狱镐保留特色 (银杆 + 金环把手 + 金色高光)。
- **剑**：刀尖收成真尖，刀身中央一条 hi 血槽，护手 + 柄头更扎实。
- **斧**：斧刃改带弧度的弯刃，留小斧背。
- **配色规矩**：暖色优先；tier 颜色已在 PALETTE 定义齐全 (木/石/铜/铁/银/金/钻石/地狱)。

### 方块
- **矿石**：复用 stone 底 + 3-5 颗带高光和黑描边的成簇矿疙瘩 (非散点)。煤=黑、铁=橙锈、铜=亮橙、锡=银白、银=亮银带蓝。
- **土/沙**：少量小石子 + 结块结构；沙加轻水平波纹。
- **冰**：偏蓝 + 斜裂纹 + 一角反光。
- **群系特色**：雪地冷白、丛林翠绿、沙漠暖黄、沼泽暗浊，让玩家一眼辨地带。
- **草/石/木**：高光与纹路微调。
