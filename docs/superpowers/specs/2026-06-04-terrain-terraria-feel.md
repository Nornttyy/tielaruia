# 地形更像泰拉瑞亚 (Terrain Terraria-feel overhaul)

用户反馈 (2026-06-04): "感觉游戏的地形不像泰拉瑞亚". 多选全中:
洞穴太细太窄 / 地表太平淡 / 矿石太零散 / 地下太单调 / 山有点低 / 还有些说不出来.

## 当前 vs 泰拉瑞亚 (调查结论)
1. 洞穴 = 细虫洞 + 6-10 格小室, 缺"大洞厅"
2. 矿 = 纯噪声单点, 不成脉
3. 地表 = 缓起伏 (AMP 0.10) + 矮山 (BOOST 0.40)
4. 地下深处单调
5. 群系离散槽位 (本次先不动)

## 分阶段 (每步独立 commit + 给用户报告)

### 第1步: 地表更壮观 ✅做这步
world_generator.gd 地表高度 = height*(BASE + n*AMP - mtn*BOOST)
- SURFACE_AMP 0.10 → 0.14 (更大起伏: 大丘大谷)
- MOUNTAIN_BOOST 0.40 → 0.60 (山更高: 峰可达 ~78 格高)
- 加一层"中丘" noise (中频) 叠加, 让起伏有大中小层次 (泰拉瑞亚味)
- clamp 保护不超界; spawn 仍可用; 树/结构仍 OK
- 测试: 宽世界地表 max-min 跨度变大 + 有高峰 (小 y)

### 第2步: 大洞厅 (big caverns)
深层 (cavern 层) 加一道"大空腔"开挖: 低频 3D-ish noise 或 BFS blob,
偶发挖 12-30 格宽的大开阔洞 (像泰拉瑞亚 cavern). 大洞底留水/矿/小平台.

### 第3步: 矿脉成簇 (ore veins)
矿从"单点噪声阈值"改"成簇": 命中阈值后 flood 周围 3-8 格同矿 (小矿脉),
或用 vein-seed 生长. 挖一片的感觉.

### 第4步: 地下更丰富
深处多样化: 更大蘑菇洞 / 大理石+花岗岩口袋 / 蛛网蜘蛛洞 / 更多深层小房间+宝箱.
