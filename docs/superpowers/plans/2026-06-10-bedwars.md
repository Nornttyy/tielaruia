# 起床战争 Implementation Plan (分 4 批)

> 设计: docs/superpowers/specs/2026-06-10-bedwars-design.md
> 测试: 先 `godot --headless --editor --quit`; 单测 `-gselect=<file.gd>`; 过滤 libfontconfig。每批跑全量不回归 + 推送。

**Goal:** 起床战争公共房 — 每人一岛(床+资源+商店), 床在能复活/床破出局, 资源生成器+商店, 最后活着的赢。

---

## Phase 1: 地基 (room + combat 重构 + 地图 + 装备 + 入口) — 先能玩

**Files:** network_manager.gd, world.gd, arrow.gd, player_action.gd, main.gd, main_menu.gd(+tscn), bedwars_arena.gd(new), locale, test

- [ ] NetworkManager: `room_mode="bedwars"` (enter_public tag "BW"); `is_bedwars()`; `combat_enabled() = is_pvp() or is_bedwars()`。
- [ ] 把"打人/不刷怪/箭命中玩家"门控从 `is_pvp()` 换成 `combat_enabled()`: world `no_mobs` + `respawn_player` pvp 判定、arrow.gd、player_action.gd `_check_sword_blade_hits` 的远程玩家扫描 + `_on_player_damaged`/死亡。(注意: PvP 专属的 PvpArena/PvP 装备/3s复活/scoreboard 仍用 is_pvp; bedwars 走自己分支)
- [ ] `scripts/world/bedwars_arena.gd`: `build(world) -> Dictionary {spawns:[Vector2..], iron_points:[...], gold_point, shop_points:[...]}`。横排 N(=8) 座岛, 每岛: 平台 + 床(BED+BED_RIGHT) + 标记生成点/商店点坐标; 中央金岛。清背景墙 + minimap mark + 永久白天 (照 pvp_arena)。
- [ ] main.gd: `is_bedwars()` 分支 → BedwarsArena.build, 玩家放 spawns[0] (Phase 2 再按 slot), 发 bedwars 装备包 (`_grant_bedwars_loadout`: wood_sword×1 + 木块/石头一叠 + 钓不到的基础); 永久白天 + relight。
- [ ] main_menu: 房间区加「起床战争房」按钮 → enter_public("BW",...); locale `mp_public_bedwars` 4 语言。
- [ ] 测试: combat_enabled 真值表; bedwars_arena 生成床在位; 按钮+回调存在。
- [ ] 全量绿 + commit + push。能玩: 进起床战争房 = 有岛有床的对战场 (暂按 pvp 3s 复活, 不判出局)。

## Phase 2: 起床规则 (slot + 床归属 + 出局 + 胜负)

- [ ] NetworkManager: `bw_assign{pid,slot}` / `bw_out{pid}` / `bw_win{pid}` 消息 + 信号; host 分配 slot (空位挑选纯函数, 可测)。
- [ ] bedwars_manager.gd: host 监 peer_joined→分 slot 广播; 监床 tile (某岛 BED 没了→标记 slot 无床); 玩家死→床在回岛复活/床破出局; 数剩余→胜负。
- [ ] bedwars_hud.gd: 各岛床状态 + 剩余人数 + 胜利/出局横幅。
- [ ] 测试: slot 分配; 床破→该 slot 不能复活; 剩 1 人→win。
- [ ] 全量绿 + commit + push。

## Phase 3: 资源生成器

- [ ] bedwars_manager (host): 每 iron_interval 在各岛 iron_point spawn `iron_ingot` drop (经现有 drop 同步); 中央 gold_point spawn `gold_ingot` (更慢)。
- [ ] 测试: 生成 tick 逻辑 (host only, interval)。
- [ ] 全量绿 + commit + push。

## Phase 4: 商店

- [ ] bedwars_shop.gd (CanvasLayer 购买面板): 靠近商店点按交互开; 商品表 (方块/剑/弓/盔甲, iron/gold 价); 扣资源给物品 (本地, 各管各背包)。
- [ ] 测试: 买得起→扣资源给物品; 买不起→不给。
- [ ] 全量绿 + commit + push。
